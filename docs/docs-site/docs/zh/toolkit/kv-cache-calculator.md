# KV Cache 容量计算器

KV Cache 计算器根据模型结构、token 数、批大小和并行配置估算 KV 数据的内存占用。它直接在浏览器中计算，无需启动模型，适合在部署前评估上下文长度和并发请求带来的容量需求。

适合在以下情况下使用：

- 增加上下文长度或批大小前，估算需要为 KV Cache 预留多少内存。
- 调整 KV 数据类型或 TP/DP 配置时，比较页面公式下的单卡与集群 KV 容量。
- 已知可分配给 KV Cache 的内存预算时，反算可容纳的 token 总量。

选择预设模型或填写支持的模型地址，设置执行参数后，可查看容量结果和计算公式。反算 token 容量时，请填写扣除模型权重、运行时开销和预留空间后可用于 KV 的内存。结果按页面中的模型公式估算，实际部署仍需核对引擎的 KV 布局与 TP 分片或复制方式。
