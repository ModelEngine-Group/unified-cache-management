# Diagnostics

UCM provides diagnostic tools to evaluate and validate your KV cache deployment before full-scale rollout.

## Key Features

- **Trace Mode**: Lightweight evaluation without actual KV cache operations
- **Hit Rate Simulation**: Estimate theoretical performance before deployment
- **Workload Analysis**: Understand your traffic patterns and cache requirements
